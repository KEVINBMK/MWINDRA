Système intelligent de sécurité minière — environnement de démonstration (données simulées, aucun capteur réel).

Accès aux postes de démo

Poste A Simulation bracelet Mesure du débit (µSv/h), niveau visuel, envoi vers la plateforme. Poste B Tableau de supervision Alertes, flux des événements, confirmation et clôture. Vue 3D Scène 3D (démonstration) Tunnel stylisé, travailleur fictif, halo selon le débit simulé — option pour suivre les mesures envoyées à l’API. Jury Présentation scénarios (Mermaid) Schémas techniques interactifs — idéal si le jury lit bien les diagrammes. Jury Scénarios animés (sans Mermaid) Même contenu que les diagrammes, expliqué en animations 2D pour les non-spécialistes. Jeu 2D Mine 2D (déplacement + zones) Vue de dessus type « jeu » : parcours dans la galerie, µSv/h fictifs selon la position, envoi API / SOS.

Référence technique

Seuils utilisés uniquement pour la démonstration : document seuils-demo.txt — ne remplace pas une étude réglementaire ni un appareil étalonné.

Réseau local : depuis un téléphone, utilisez l’adresse IPv4 du PC (Wi‑Fi), par ex. http://192.168.x.x:8000/bracelet (remplacez par l’IPv4 Wi‑Fi du PC) — ne pas utiliser 127.0.0.1 sur l’appareil mobile.

Projet de cadrage MVP — API locale FastAPI. Pour toute question d’intégration, voir le dépôt MWINDRA sur GitHub.
